# 05 — 内容与视频

> 给俊宇：内容的目的不是爆红，而是让对的人**信任你**，然后私信你。每天 1 支短视频，持续 30 天。
> 给 Claude Code：任务 5.1–5.4 用这份文件。所有平台费率、工具价格、平台规定，用之前先查最新资料。

## 1. 目标

- 建立信任：让商家看到你真的懂、真的做得出来
- 带来私信：每支视频都有清楚的行动呼吁
- 累积素材：好的视频以后可以拿来投广告

**前 30 天目标：** 发布 20 支以上；从内容来的私信 3 个以上。

## 7. 制作流程（不露脸 + AI）

### 7.1 四种形式

| 形式 | 做法 | 适合 |
|---|---|---|
| **手机录屏 + 自己配音（主力）** | 用手机录网站操作，后期配音 | 作品、技巧、算账 |
| 电脑录屏 + 配音 | 录 Claude Code、后台操作 | AI 幕后 |
| AI 数字人 | 用 HeyGen 等工具的数字人讲解 | 开场介绍、FAQ |
| 混剪 | AI 生成的空镜 + 字卡 + 录屏 | 痛点、故事 |

真实录屏 + 你自己的声音最有说服力。数字人可以用，但不要整个频道都是数字人。

### 7.2 工具

| 用途 | 工具 | 备注 |
|---|---|---|
| 写脚本 | Claude | 用第 6 节模板 |
| 手机录屏 | 手机内建录屏 | 天生直式 9:16 |
| 电脑录屏 | OBS Studio（免费）或 Windows 内建录屏 | |
| 配音 | 自己的声音（推荐）；或 ElevenLabs 等 AI 配音 | |
| 数字人 | HeyGen、Synthesia 等 | 只用自己的数字人或平台授权的形象 |
| AI 空镜 | Veo（写实动态）、Runway（改现有视频）、Kling 等 | |
| 剪辑 + 字幕 | 剪映 / CapCut | 自动字幕、加速、放大 |
| 封面 | Canva 或剪映模板 | |

工具的功能和价格变化很快：先用免费方案，付费前查最新价格。

### 7.3 每周批量制作

| 时间 | 做什么 |
|---|---|
| 周日（30 分钟） | Claude Code 出下周 7 个脚本 + 画面清单 |
| 周一（2 小时） | 一次录完所有录屏和配音 |
| 周二（2–3 小时） | 剪 7 支（套同一个剪辑模板：字幕样式、开头、结尾） |
| 周三起 | 每天发 1 支，回复留言和私信 |

### 7.4 录屏小技巧

- 手机录屏最适合短视频；电脑录屏要在剪映里放大重点区域
- 开勿扰模式，避免通知跳出来
- 只用示范资料。**不要露出**真实客户资料、密码、后台敏感资讯
- 无聊的部分加速 2–4 倍
- 样板站介绍视频（任务 2.3）：首页往下滑 → 点一个产品 → 选规格 → 加入购物车 → 结账页 → WhatsApp 按钮，全程 60–90 秒

### 7.5 AI 配音

- 先试自己的声音，通常最可信
- 用 AI 配音时选自然的声音，语速稍快
- 不要模仿名人或别人的声音

### 7.6 AI 数字人

- 只用自己的数字人（按平台要求录授权影片）或平台提供的授权形象
- 不要假装是另一个真人
- 在简介或视频里说明有用 AI

### 7.7 AI 空镜（B-roll）

用在开场和转场。提示词范例：
- `close-up of hands packing skincare bottles into a kraft paper box on a wooden table, soft natural light, vertical 9:16`
- `smartphone on a desk showing a new order notification, shallow depth of field, warm tone, vertical 9:16`
- `small business owner working on a laptop in a bright home office, candid, vertical 9:16`

不要生成真实品牌的 logo、名人、真实客户的店面。

### 7.8 封面与标题

- 封面字 = 钩子，最多 8–10 个字
- 所有视频用统一的字体和颜色，让人一眼认出是你

### 7.9 AI 标注

写实的 AI 画面或数字人，按各平台的规定开启 AI 内容标注。

## 8. 发布与互动

- **时间：** 先测试中午 12–2 点和晚上 8–10 点，两周后看自己的数据决定
- **文案公式：** 钩子 → 2–3 行重点 → 行动呼吁（"留言「X」"、"私信我"、"点主页链接"）
- **Hashtag：** 3–5 个（1 个行业大标签 + 2 个本地标签 + 1–2 个主题标签）
- **置顶留言：** 重复行动呼吁 + 链接
- **回复：** 24 小时内回每一条留言；留言关键字的人，私信一次，给他要的东西
- **一鱼多吃：** 同一支视频发 TikTok、IG / FB Reels、YouTube Shorts；小红书可以改成图文
- **音乐：** 用平台提供的可商用音乐（TikTok 商业账号要用商用音乐库），不要用流行歌

## 9. 广告（Phase 7：有 2–3 个真实案例之后）

### 9.1 Meta 点击跳 WhatsApp 广告

- **前提：** 有 2–3 个真实案例，或表现好的自然流量视频
- **目标：** 在 Ads Manager 选可以把对话导到 WhatsApp 的广告目标（例如「互动」或「潜在客户」，以当时的介面为准）
- **受众：** 马来西亚、22–55 岁；先试宽泛受众 + 好素材，或兴趣（小企业、网店、Shopee、TikTok Shop、创业）
- **素材：** 自然流量表现最好的 2–3 支视频
- **预算：** 每天 RM30–50，先跑 7 天
- **WhatsApp：** 设好自动问候 + 1–2 个快速问题（"你的店在哪个平台？卖什么？"）
- **看的数字：** 每个对话的成本、合格对话比例（真的有店、有预算）、每个通话的成本、成交数
- **规则：** 跑满 7 天再判断；第一周的数字当基准；之后关掉成本最高的素材，把预算加给最好的

### 9.2 Google 搜索广告（可选）

- **关键字（例子）：** woocommerce malaysia、website kedai online、buat website jualan、online store website malaysia
- **否定关键字：** free、percuma、course、kursus、job、kerja、template、tutorial
- **落地页：** 工作室网站的套餐页（不是首页）
- **转换：** 表单提交 + WhatsApp 点击（GA4 事件导入 Google Ads）
- **预算：** 每天 RM20–30，先跑 14 天

### 9.3 广告诚信

- 不写"保证上 Google 第一页"、"保证销量"
- 案例和数字都要真实，客户同意才用
- 不用竞争对手的品牌名当关键字

## 10. 每周复盘

`content/calendar.csv` 每周填：播放数、完播率、留言、私信数。

每周日 Claude Code 出复盘：
- 这周发了几支（目标 5–7）
- 表现最好的 3 支：哪个钩子、哪个支柱
- 表现最差的 3 支：可能的原因
- 带来几个私信、几个变成潜在客户
- 下周调整：好的选题做续集或换角度；差的换钩子重拍
