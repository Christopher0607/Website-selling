# 11 — 销售工作台（找商家 → AI 写信息 → 你按发送 → 自动提醒跟进）

> 网址：**https://cartsmithstudio.com/desk/**（有密码，只有你能用；不会被 Google 收录）
> AI 用的是已经放在 Netlify 的同一把 DeepSeek Key，**不用把 Key 给任何人**。

## 它帮你做什么

| 你做 | 工作台自动做 |
|---|---|
| **不用做**：Claude Code 上网找的商家会自动出现在「今天」最上面的「新商家」，你只按「全部加入」 | DeepSeek 逐家打分、写好开场白（资料不用复制粘贴） |
| 自己在 Shopee / IG 看到合适的店，把资料贴进「加商家」 | DeepSeek 打分（5 个条件）、判断值不值得联系、建议用哪个模板、用对方的语言写开场白、存进名单、检查有没有重复 |
| 在「今天」每张卡的「发送」选一种：**WhatsApp**（信息已经填好）、**Email**（主旨和内容已经填好）或 **Instagram**（信息已复制，长按贴上）→ 看一遍、按发送 → 回来按底部提示条的「已发送」 | 记录日期；第 3 天提醒你跟进（AI 写好「有用资讯」那一条）；第 10 天提醒最后一条；3 次都没回就自动结束 |
| 对方回复了：把回复贴进来 | AI 判断对方的意思（有兴趣 / 问问题 / 异议 / 不要）、写好回信、建议下一步 |
| 对方说不要：按「对方说不要」 | 永远不再出现在联系清单（诚信守则） |
| 打开对方 IG 主页时看到电话 / Email / Linktree：按卡片上的「补上 WhatsApp / Email」贴进去 | 号码自动整理成国际格式（012-345 6789 → +60 12-345 6789），之后就能一键用 WhatsApp / Email 发 |
| — | 每天新联系上限（默认 10 个，保护你的 IG / WhatsApp 帐号）、样板 14 天到期提醒、每周数字（也分 IG / WhatsApp / Email）、导出 CSV |

**不会做的事：** 不会自动发信息（每条都由你按发送）、不会自动去 Shopee / Instagram 抓资料（违反平台规定，会被封号）。
**AI 写的信息：** 用「Cartsmith Studio」和「我们」的名义，不写你的名字，不用表情符号；同一段话可以直接用在 IG、WhatsApp 和 Email。
**新商家一定有 IG**（2026-11-08 起）；WhatsApp / Email 是 Claude Code 从公开资料找到的（报道里的订购电话、Google 商家资料、Linktree），找不到就留空，由你在对方主页看到时补上。
Claude Code 找资料只用搜索引擎和新闻报道，再直接试对方有没有网站（`.com / .com.my / .my / .co`），不登录、不刷 IG。

## 设定（只做一次，5 分钟）

1. **想一个工作台密码**：至少 12 个字，例如三个英文字 + 数字（`mango-river-desk-2026` 这种）。**存进你的密码管理器**（Bitwarden 或手机自带的）。不要用你的 Instagram 或银行密码，也不要贴到聊天里。
2. Netlify → 你的网站 → **Project configuration → Environment variables → Add a variable → Add a single variable**
   - Key：`SALES_DESK_KEY`
   - Value：你的工作台密码
   - Scopes：至少勾 **Functions**
   - 按 **Create variable**
3. 左边菜单 **Deploys → Trigger deploy → Deploy project**，等变绿色（1–2 分钟）。
4. 用手机打开 https://cartsmithstudio.com/desk/ → 输入密码 → 进入。
5. **放到手机主画面**（像 App 一样一按就开）：Chrome 右上角 ⋮ → **加到主画面（Add to Home screen）**。

> 打开工作台显示「工作台密码还没设定」= 第 2–3 步还没做好。显示「密码不对」= 输入的跟 Netlify 里的不一样（注意大小写和空格）。

## 每天怎么用（约 30–40 分钟）

> **AI 看得到整个系统（2026-11-10）：** 工作台的 DeepSeek（写开场白、跟进、分析回复、每家的 AI 助手）每次都会读：现在的销售流程和规则（`sales/agent/desk-brief.md`）、工作室知识库和价钱，以及这一家的全部资料：状态、电话记录、整段对话、卡片上准备好的信息，还有**样板里放了什么**（每样产品和价钱、价钱的来源年份、哪些是问价、哪些是我们建议的 Example、地址、营业时间、FAQ）。对方问「这个价钱哪来的」「照片是我们的吗」，AI 会照实回答。

> **适合他的示范（2026-11-12）：** 有样板的卡片会多一行「适合他的示范」：工作台按这一家的行业自动选一个完整示范网站（精品餐厅 → Maison Cendre；一般餐厅、咖啡馆 → Sireh & Salt；烘焙、糕点、kuih、甜品、咖啡豆、酱料、礼盒 → Dulang & Daun；不是餐饮的没有），旁边是节日预购页 RM399 的示范（华人店开农历新年版、马来店开开斋节版）。第二通电话的台词多了「2b 完整示范」；发样板后的第一条跟进信息会附上这两个网址，并写出三种开始方式：RM800 起一次付清、不用先付钱每月 RM199 × 12、节日预购页 RM399。卡片的 AI 助手也知道该给哪个示范。

> **任务面板和连续打电话（2026-11-10）：** 「今天」最上面告诉你现在几点适合打给谁、有几家要打电话 / 要发样板 / 要跟进、今天做了多少。按「开始连续打电话」：一家一家显示拨号按钮、**对方语言的 4 步台词（下面附中文意思，店名和样板里的产品已经填好）**、8 种常见回话（每种有对应按钮）、结果按钮；说可以 → 马上出现填好网址和密码的信息 → 按 WhatsApp 发 → 「已发样板，下一家」。发样板两天后，「今天要跟进」会出现准备好的跟进信息（再附一次网址和密码，请对方传照片和价钱）。卡片上写「样板已检查 日期」= Claude Code 已经在线上检查过，可以直接发。

> **已经做好样板的店（2026-11-10 起）：** 卡片只显示一段短信息：一句介绍我们是谁 → 已经帮你们做好免费样板网站（网址 + 密码）→ 最后附上 Cartsmith 的网站。不再写一大段对方店的介绍。先按「打电话」，对方说可以，就按「WhatsApp +60 …」：直接打开对方号码的对话，信息已经填好，你看一遍按发送，回来按「已发送 / 已发样板」。只有电话号码（01x 开头）的店也会出现 WhatsApp 按钮。WhatsApp 不允许网站替你按发送，所以最后一下还是你按。

0. **新商家（1 分钟）**
   - 「今天」最上面有「新商家 · Claude Code 找的」→ 不合适的按「跳过」→ 按「全部加入」，等 AI 逐家写好（每家约 8 秒）。
   - 资料来源：Claude Code 写进 `sales/leads/*.json`、push 之后 Netlify 自动部署，工作台就会出现。
   - 卡片上的「发之前看一眼」是 Claude Code 看不到、要你确认的事（例如 IG 简介有没有网站链接）。
1. **自己加商家（选做）**
   - 在 Shopee / TikTok Shop 搜关键词（`sales/find-customers.md` 有清单），点进店，看简介有没有 IG。
   - 打开工作台 →「加商家」→ 贴上：店名、店铺链接、IG、卖什么、评价数 / 粉丝数、有没有网站、**一个具体观察** → 按「AI 分析并加入名单」。
   - 分数 3 分以上会出现在「今天」；低分的在「名单 → 低分」（建议跳过）。
1b. **先打电话（2026-11-09 起，主要的第一步）**
   - 时段：餐厅、咖啡馆平日 14:30–17:00；卖产品的 10:00–12:00。在午餐、晚餐时间或晚上按「打电话」/ WhatsApp，工作台会先提醒你。
   - 卡片上按「**打电话**」（手机会直接拨号），卡片里的「电话开场」可以照着念；完整脚本和各种回话：工作台右上角「电话脚本」。
   - 打完按结果：**可以发样板**（卡片移到「有回复，等你回」，已经写好「刚刚通过电话」的 WhatsApp，做好样板后贴上网址和密码再发）/ **没接**（隔天再出现；3 次没接就改发信息）/ **改天再打**（选日期，到了那天出现在「今天要打电话」）/ **不需要**（不再联系）。
   - 「名单 → 拜访清单」：有地址的商家按地区排好，附 Google 地图。每周挑两个下午去同一区走 8–10 家。

1e. **对方回复时，整段对话都要记（2026-11-09）**：按「贴上对方的回复」时，上面贴对方说的（可以好几条），下面贴**你自己在 IG / WhatsApp 直接回过的话**（不是用工作台发的才要贴）。工作台发出去的信息会自动记下全文。AI 会看整段对话再判断——例如对方说「已经有网店」、你也已经礼貌结束、对方回「好的」，AI 会说不用再回、建议结束，而不是继续推销。对方已经有网站：卡片「···」或「记录进度」→「对方已经有网站」（可以填网址），这一家就结束、不再提醒跟进；没兴趣就按「没成交」。

1d. **样板表（2026-11-09）**：「名单 → 样板表」把有样板的商家排成一张表：店名、状态、电话（按一下拨号 / WhatsApp）、样板（打开）、密码（复制）、删除日期（到期变红）、地区、最后联系、下一步。手机上可以左右滑，店名那一栏固定在左边。「显示全部商家」看全部；「复制整张表」可以贴到 Notes 或 Google Sheets；「卡片」跳到那一家的卡片。CSV 备份也有样板密码。

1c. **每一家的 AI 助手（2026-11-09）**
   - 每张卡片右下角有「**AI**」按钮（后面的数字 = 这一家聊过几条）。打开后可以：贴上对方的 WhatsApp / IG / Email 回复，请它帮你回；问「下一步该怎么做」「对方问价钱怎么回」「帮我写跟进」。
   - AI 回答里如果有「可以直接发的信息」框，按「复制」或「WhatsApp」就能发（还是你自己按发送）。
   - **每一家是分开的**：问 A 家的时候，AI 只看得到 A 家的资料、联系记录、样板和跟 A 家的对话，不会混到别家。**不会忘记**：对话一直保存在工作台（Netlify Blobs，私人的，不放 GitHub——GitHub 是公开的）；聊很多之后会自动整理「AI 记住的重点」。
   - 备份：「数字 → 设定 →下载完整备份（含 AI 对话）」会下载一个 JSON 档案，存在安全的地方（里面有客户资料，不要传给别人）。
   - AI 用 DeepSeek（每次问大约几分钱以下），价钱和条款以 `site/studio.json` / 报价单为准；AI 不确定的会说不确定。

2. **发信息：用「连续发送」（50 家大约 15–20 分钟）**
   - 「今天」→「新联系」上面的黑色横条「连续发送」→ 按「开始」。一次只出现一家（有 WhatsApp / Email 的排前面）。
   - 按 **WhatsApp**（信息已经填好）或 **Email**（主旨和内容已经填好）→ 在 App 里看一遍、按发送 → 回到工作台按「**已发送，下一家**」。不想发的按「跳过」（不记录，之后还会出现）。
   - 每天上限在「数字 → 设定」改（最多 100，2026-11-08 起）。**WhatsApp 一天发很多陌生人，被检举几次就可能被封**：WhatsApp 每天最好不超过 30–40 个，其余用 Email；第一周先少一点。
   - 也可以照下面的方法一张一张卡片发：
   - 「今天」→ 每张卡：看一下开场白（可以直接改）→ 在「发送」选 WhatsApp / Email / Instagram（**有 WhatsApp 就先用 WhatsApp**，很多商家比较常回）→ 看一遍、按发送 → 回到工作台，底部会问「用 ○○ 发给 ○○ 了吗？」→ 按「已发送」。
   - 卡片显示「补上 WhatsApp / Email」：先按 Instagram 打开对方主页，看简介里的「联系」按钮、电话、Email 或 Linktree；有的话复制，按「补上 WhatsApp / Email」贴进去。只用对方公开给客人的联系方式。
   - 对方说不要、请你别再发：马上按「对方说不要」，不管是哪个渠道。
   - 右上角会显示「今天新联系 x/10」，满了就停。
3. **回复和跟进（10 分钟）**
   - 「有回复，等你回」：按「贴上对方的回复」→ AI 写好回信 → 复制、发送 →「记录进度」选现在的状态（已回复等对方 / 样板已发 / 约了通话……）。
   - 「今天要跟进」：按「AI 写跟进信息」→ 复制、发送 →「已发送」。**跟进时换一个渠道**：上次用 Instagram 的，这次 WhatsApp 按钮会排在第一个，卡片下面也会写「上次用 Instagram，这次可以换 WhatsApp」。同一条信息只用一个渠道发，不要 WhatsApp、Email、IG 同时发同一句（对方会觉得被轰炸、容易被检举）。
   - 每天早上的定时任务也会帮还没有 WhatsApp / Email 的商家再找一次（只用公开网页）；找到会自动补进卡片。只经营 IG 的小品牌通常只把号码放在 IG 主页，这种还是要你打开主页看一眼、按「补上 WhatsApp / Email」。
4. **对方有兴趣要样板**：照 `docs/09-netlify-guide.md` 第 D 部分做样板 → 发出 → 卡片「⋯ 更多 → 样板已发」填网址（14 天后提醒你删除）。

## 每周日

- 「数字」看：联系过几个、回复率、几个样板、几个通话、几个成交。联系满 20 个后会提示「最弱的一步」。
- 「数字 → 下载名单（CSV）」备份一次（也可以发给 Claude Code 帮你分析）。

## 资料存在哪里、安不安全

- 名单存在你的 Cloudflare 帐号里（D1 资料库，2026-11-12 起；以前在 Netlify Blobs），只有知道工作台密码才看得到。
- 名单只记录商家**公开的商业资料**（店名、店铺链接、IG），只用来联系对方本人，不分享、不卖。
- 密码外泄：在 Cloudflare 把 `SALES_DESK_KEY` 改成新密码 → Retry deployment。密码错 10 次会锁 10 分钟。
- **备份 / 换帐号：** 「数字」→「下载名单（CSV）」就是完整名单；换 Netlify 帐号后，在新工作台「数字」→「从备份还原」选那个档案（已经有的商家会跳过）。
- 费用：AI 用 DeepSeek 余额（每次分析很少）；Netlify 储存用量很小，在免费额度内。

## 测试记录（2026-11-08）

- ✅ 本地完整测试（模拟 DeepSeek）：密码错误会拒绝；加商家 → 打分 4/5、5 个条件、开场白；复制并打开 `ig.me/m/<账号>`；已发送 → 计数、3 天后跟进；到期出现在「今天要跟进」→ AI 写跟进；贴上回复 → AI 判断意思 + 回信；记录样板（14 天删除日期）；不再联系；名单筛选 / 搜索；数字；导出 CSV；没有 JavaScript 错误
- ⏳ 线上：等你设定 `SALES_DESK_KEY` 后，用真的 DeepSeek 加第一个商家试

## 样板有没有被打开（2026-11-11）

每个样板的密码页会通知工作台「有人打开了」，所以你可以知道对方到底有没有点进去看。

- **卡片上（样板那一格）：**「看过样板 2 次 · 1 部手机 · 7 页 · 约 3 分钟 · 最后 今天 15:20 · 看了：首页、全部产品、Classic Tiramisu」。
  - 「打开了链接，但还没输入密码」：可能找不到密码，跟进时再发一次网址和密码。
  - 「对方还没打开过样板」：发了但还没看。
  - 「还试了下单流程」：对方点了购物车或结账，是兴趣很高的信号。
- **「今天」最上面：**「刚看过样板（48 小时内）：趁现在跟进」，按「打电话」或「打开卡片」。
- **样板表：** 多了一栏「打开过」。
- **你自己看不算：** 在一台手机或电脑上用新网址 https://cartsmithstudio.com/desk/ 打开过工作台，那台设备看样板就不算进去，只会显示「你自己看过 N 次（不算）」。用旧的 netlify 网址打开样板不会被认出是你。
- **我们的自动检查、WhatsApp 的链接预览都不算。**
- **不记录个人资料：** 不存 IP、名字、电话；只记时间、看了哪一页、手机还是电脑，和样板在那个浏览器里存的一个随机编号（用来分辨几部设备）。
- **不要跟客户说「我看到你打开了」**，只用来决定什么时候打电话、跟进要不要重发密码。工作台的 AI 也照这个规则。
- 资料存在 Cloudflare D1（`view:<样板>`），程式在 `site/server/desk.mjs`（`/api/track`）和 `scripts/local/preview-publish.js`（密码页）。

## 完整备份和还原（2026-11-12）

- 「数字」→ **下载完整备份（含 AI 对话）**：一个 JSON 档案，有每张卡的全部资料、联系记录、样板网址和密码、AI 助手的对话。里面有样板密码，不要传给别人、不要放进 GitHub。
- 「数字」→ **从备份还原**：选那个 JSON。新的空工作台会整份还原；已经有名单的工作台只补上缺的商家，并把不见了的 AI 对话放回去，不会重复。
- 换 Netlify 帐号的步骤见 `docs/09-netlify-guide.md` 第 F2 部分。

## 网站上的新申请（2026-11-12）

- 网站的「免费样板申请」表单，和 AI 客服留下的联络资料，会出现在「今天」最上面的「网站上的新申请」。
- 看过后按「已看过」。要加进名单，请到「加商家」把资料贴进去。
- 以前用 Netlify 的表单服务（会寄电邮）；现在存在工作台，不会寄电邮，记得每天看一下工作台。
