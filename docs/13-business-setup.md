# 13 开业清单：收第一笔订金之前要做好的事

> 2026-11-15 写（俊宇：先当作 The Baking Trip 已经要了，把 SSM 等所有东西准备好）。资料都在 2026-11-15 上网查过，来源在每一节下面；规定和收费会变，**办之前再看一次官方网站**。法律、税务的部分是整理给你参考的，最后请会计 / 律师确认。

## 顺序（为什么要这样排）

1. **SSM 注册**（1 个工作天左右）——没注册就收客户的钱是违法的（Registration of Businesses Act 1956）。
2. **开商业银行户口**（要 SSM 证书）——订金、尾款、月费都进这个户口，不要用个人户口。
3. **报价单 → 合约 → 订金单**（模板已经做好，见第 4 节）——客户签了合约、付了订金才开工。
4. **收据**——每收一笔钱就开一张。
5. **记帐和报税**——从第一笔收入开始记。

## 1. SSM 注册（独资，商号 Cartsmith Studio）

**要准备：** 你的 MyKad（年满 18 岁）、手机、一个能收信的电邮、做生意的地址（可以先用住家地址）、网上付款（卡或网银）。

**步骤（用手机就可以）：**
1. 打开 **ezbiz.ssm.com.my**，按「Register」开帐号（用 MyKad 号码），电邮里按确认连结开通。
2. 登入后选 **New Registration → Local Business（本地生意）→ Sole Proprietorship（独资）**。
3. **商号**：填 `Cartsmith Studio`（系统要你填 3 个名字、按顺序，第 2、3 个可以填 `Cartsmith Studio Enterprise`、`Cartsmith Web Studio`）。用商号要先批名字；用自己 IC 上的名字就不用批，但是比较不像一间工作室。
4. **生意性质（MSIC 代码）**：在系统里搜「website」「computer programming」「web design」，选最接近「电脑程式设计 / 网站设计」的那一个（常见的是 62010 *Computer programming activities*，我不确定是不是最合适，以系统的说明为准；可以选 2–3 个）。
5. 填生意地址、开始日期，确认资料，**付费**。
6. 等批准（来源说通常 1 个工作天内，资料正确有时候 1 小时）。批准后在 ezBiz 下载 **商业注册证书（e-SSM / Borang D 的电子版）**，存进手机和电脑。

**收费：** 用商号 **RM60 / 年**；用自己 IC 名字 RM30 / 年；有分行每间加 RM5 / 年。**每年要续**（到期前在 ezBiz 续）。

**注册好之后：**
- 把 SSM 号码告诉我：报价单、合约、收据、订金单都会印上。
- SSM 批准信里可能有 **.com.my 域名优惠连结**（MYNIC 和 SSM 的合作，新注册的生意 RM60 / 年；一般价钱大约 RM80 / 年）。我们已经有 cartsmithstudio.com，不一定要买；要买的话用那个连结。

来源（2026-11-15 查）：[SSM：新生意注册指南（PDF）](https://www.ssm.com.my/Documents/Ezbiz%20Online%20User%20Guideline/GUIDELINE-FOR-REGISTRATION-OF-NEW-BUSINESS.pdf)、[RinggitPlus：第一位客户付钱之前要搞定的事](https://ringgitplus.com/en/blog/sme/what-to-sort-out-before-your-first-customer-pays.html)、[Tune Protect：注册生意](https://sme.tuneprotect.com/registering-your-business/)、[SSM：域名 FAQ（PDF）](https://www.ssm.com.my/Pages/FAQ/FAQ-Domain-En.pdf)

## 2. 商业银行户口

**要准备：** SSM 商业注册证书、MyKad、开户的最低存款。
- 大部分银行可以在网上开始申请，但很多还是要去一次分行完成。
- 最低存款每间银行不一样：网上开户有的 RM100，分行开户有的 RM1,000–3,000。去之前看银行网站，或打电话问。
- 例子（2026-11-15 查到的资料，要去银行网站确认）：
  - **Maybank SME First**：独资可以网上开通，之后可能要去分行；
  - **CIMB**：网上申请 + 分行；
  - **Hong Leong PrimeBiz**：来源说独资可以全程网上办。
- **建议：** 选你个人户口所在的那间银行，转帐和 DuitNow 最方便。开好后申请这个户口的 **DuitNow QR**：客户付订金、月费可以扫码。
- **没有本金（2026-11-15 俊宇问）：** 最低存款最少的几个（第三方网站的资料，开户前看银行官网）：
  - **GXBank 商业户口**：只给独资，来源说开户存款 RM10 或 0、没有最低余额，全程用 App；
  - **Maybank SME First**：用 MAE App 转帐开户 RM100（去分行要 RM1,000）；
  - HSBC / UOB 的基本户口：RM100。
  - 所以开始只需要 **SSM RM60 + 开户 RM10–100，大约 RM70–160**。第一位客户的订金（Growth 是 RM800）会进这个户口，之后的开销都可以用订金付。
  - 来源：[Airwallex：Maybank 商业户口](https://www.airwallex.com/en-my/blog/maybank-business-account-review)、[Airwallex：免费商业户口](https://www.airwallex.com/en-my/blog/best-free-business-bank-account)、[WorldFirst：中小企业户口比较](https://www.worldfirst.com/my/blog/business-bank-insights/best-sme-bank-accounts-malaysia/)、[Maybank SME First](https://www.maybank2u.com.my/maybank2u/malaysia/en/business/deposits/deposit_account/sme_first_investment_i.page?)

来源：[WorldFirst：独资银行户口](https://www.worldfirst.com/my/blog/business-bank-insights/sole-proprietorship-bank-account-malaysia/)、[Curlec：开商业户口步骤](https://curlec.com/blog/how-to-open-a-business-bank-account-in-malaysia/)、[Maybank SME First 网上开户 FAQ（PDF）](https://www.maybank2u.com.my/iwov-resources/pdf/business/deposits/sme1st-activate-biz-acc-faq.pdf)

## 3. 电子发票（e-Invoice）、收据、报税

- **电子发票：** LHDN 的 e-Invoice 指南 4.8 版（2026-08-30）把豁免门槛提高到 **年营业额 RM3 百万以下**。我们远远低于这个数，所以**不用开电子发票**，开一般的发票和收据就可以。
  - 有来源提到：豁免的商家遇到很大笔的单一交易（RM10,000 以上）可能还是要开电子发票。我们的单子都低于这个数，请会计确认。
  - 来源：[Bernama](https://bernama.com/en/news.php?id=2601057)、[Malay Mail 2026-08-31](https://www.malaymail.com/news/malaysia/2026/08/31/irb-stresses-voluntary-participation-as-government-lifts-einvoice-threshold-easing-compliance-for-msmes/233340)、[VATupdate](https://www.vatupdate.com/2026/09/08/malaysia-raises-e-invoice-exemption-threshold-to-myr-3-million/)
  - 我没打开 LHDN 的原文，最后以 LHDN 网站或热线 03-8682 8000 为准。
- **发票和收据：**
  - 每收一笔钱就开收据，号码按顺序（例如 `CS-2026-001`）。
  - 收据存两份：一份发给客户，一份自己留。
  - 模板见第 4 节，我帮你填好、转成 PDF，你用 WhatsApp 发。
- **报税：**
  - 独资的收入算你个人的生意收入，每年报一次（一般是 Form B，截止日期请会计确认）。
  - 从第一天开始记帐：哪天收了谁多少钱、哪天付了什么费用（服务器、域名、Claude、DeepSeek……）。
  - 我可以帮你做一个简单的记帐表。
- **SST：** 小生意营业额没到门槛就不用登记。我没有查最新门槛，开始赚钱后请会计看。
