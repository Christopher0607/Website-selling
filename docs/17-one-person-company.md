## 二、设计：6 个 agent + 1 个「待批准」

每个 agent 的工作都直接变成工作台里的东西（卡片、信息、报价、网站），用真的结果来算（发出几条、几个回复、几张报价、收到多少钱），**不是写报告**。这是跟 MAUS 最大的不同。

| Agent | 自己做（不用问你） | 交给你批准 |
|---|---|---|
| 总监（= 现在的总助理） | 每天早上整理：昨天做了什么、今天要你批准什么、数字 | — |
| 销售 | 收件箱自动加入、打分、写第一条；排今天要发的（第一条 + 到期的跟进）；你贴进来的回复，起草回答 | 今天要发的信息（批准后你按发送） |
| 报价 | 老板说有兴趣 → 起草书面报价和订金连结 | 报价和价钱 |
| 找客户 | 每天找新商家、查有没有网站、放进收件箱 | —（只是放进名单） |
| 建站 | 收到订金 → 发资料表给客户 → 用模板自动建 WordPress 网站 → 跑全部测试 → 做好预览 | 预览给客户看之前、正式上线 |
| 品质 + 财务 | 每晚检查所有网站和示范；每月维护报告草稿；记订金、月费、提醒；每周数字 | 发给客户的报告、催款信息 |

**正循环：** 每周数字（联系 → 回复 → 报价 → 成交 → 收入 → 成本）告诉找客户 agent 下周找哪一类商家；成交的客户同意后做成真实作品案例，放上网站，让下一家更容易成交。

## 三、一定要经过你的事（human in the loop）

1. 发给一家新商家的第一条信息
2. 报价、价钱、折扣
3. 网站给客户看、正式上线
4. 花钱（任何付费服务、升级）
5. 删除任何东西
6. 用 Cartsmith 名义发给客户的任何东西

其他全部 agent 自己做。DeepSeek 每月有花费上限（默认 USD 10），到了 agent 就停下来等你。

## 四、还是要守的三条（不是喜好，是犯了直接有损失）

1. **WhatsApp / Instagram 不能让机器自动发第一条给没同意过的人。** WhatsApp 规则写明要对方先同意（2026-11-22 查 whatsappbusiness.com/policy），网上找到的号码不算；被检举多了号码会被限制或封掉。所以「发送」= 系统排好、你一条按一下（约 1 分钟一家，一天 30 家做得到）。客户**自己先传信息来**的，24 小时内系统可以用 WhatsApp API 回（第 3 阶段）。
2. **不造假：** 不写假评价、假客户、假数字。
3. **Google 地图的商家资料不能存进名单**（Google 条款不准保存商家名字和地址，2026-11-22 查）。找客户要用公开文章 / 名单 + 查网域，或其他合规的来源。

## 五、分阶段

- [ ] **第 1 阶段：自动销售循环（不花钱，用现有的 Cloudflare + DeepSeek）**
  Cloudflare 定时（Cron Trigger）每天早上叫 agent 做事：收件箱自动加入、排好今天要发的、到期跟进写好、有兴趣的起草报价；工作台新分页「待批准」；总监早报；agent 工作记录（做了什么、花了多少）。目标：你每天约 20–30 分钟——看早报、批准、按发送、跟回复的老板谈。
- [ ] **第 2 阶段：自动建站 + 找客户 + 检查**（2026-11-24 先做了「找客户」：GitHub Actions 每天的找客户机器人，见 `sales/leads/README.md`）
  客户资料表 → 产品资料 → DigitalOcean 服务器自动建站（服务器定时去工作台拿「要建的站」）→ Layerbeat VPS 跑全部测试和截图 → 预览给你批准。找客户 agent（来源先查清楚条款和价钱）。Instagram 帖子 agent：做好图文，你批准后用 Instagram 官方 API 自动发到 @cartsmith.studio（官方允许）。
- [ ] **第 3 阶段：回复和收钱**
  WhatsApp 官方 API 接客户主动传来的信息（agent 起草，你批准后回）；订金 / 月费记录和提醒；每月维护报告。
