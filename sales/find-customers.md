# 找客户速查表（手机看这一页就够）

> 完整版在 `sales/playbook.md` 和 `docs/04-sales-kit.md`。话术在 `sales/scripts.md`。
> 原则：**一个一个手动找、一个一个手动发**。不用程式抓资料、不群发、对方说不要就停。
> **2026-11-08 起用销售工作台**：https://cartsmithstudio.com/desk/ （设定和用法：`docs/11-sales-desk.md`）。下面的「贴给 Claude Code 的格式」，现在直接贴进工作台的「加商家」。

## 每天的节奏（约 1 小时）

| 时间 | 做什么 |
|---|---|
| 30 分钟 | 找 10–20 个店（下面的方法），资料贴进工作台「加商家」 |
| 自动 | 工作台的 AI 打分、写好每个人的开场白（中 / 英 / 马来文） |
| 20 分钟 | 在 Instagram 一条一条复制、贴上、发出（早上 9 点到晚上 9 点） |
| 5 分钟 | 回复所有回你的人（回复贴进工作台，AI 写回信）；发了就按「已发送」 |

新账号**前两周每天新私信 10 个以内**，之后最多 20 个（太多会被 Instagram 限制）。

## 去哪里找

**Shopee / TikTok Shop（最好）**：搜关键词 → 点进店 → 看简介有没有 Instagram。
- 护肤美妆：`serum`、`sunscreen`、`skincare local`、`toner`
- 服装：`baju kurung`、`tudung`、`oversized tee`、`muslimah wear`
- 食品：`sambal`、`kuih raya`、`cookies`、`frozen food`、`kerepek`
- 咖啡茶：`kopi`、`coffee beans`、`drip bag`
- 宠物：`cat food`、`pet shop`、`dog treats`
- 3C 配件：`phone case`、`power bank`、`cable`

**Instagram**：搜 hashtag，例如 `#localbrandmalaysia`、`#skincaremalaysia`、`#sambalviral`、`#kuihraya`、`#tudungmurah`，挑**简介只有 WhatsApp / Shopee / Linktree、没有自己网站**的品牌。

## 怎么判断值不值得联系（每个店 1–2 分钟）

要找：
- ✅ 有自己的品牌名和 logo（不是卖杂货、代购）
- ✅ 卖得不错：Shopee 评价大约 300–20,000 条，或 TikTok 常开直播
- ✅ 最近 7 天有发文或直播
- ✅ 没有网站，或网站很旧、手机不好用
- ✅ 看得出有预算：专业产品照、有投广告、有实体店

不要找：Shopee Mall 大品牌、已经有很好网站的、还没有产品的新手、卖仿冒品的。

## 贴给 Claude Code 的格式（照抄，空的可以不填）

```
1. 店名：
   Shopee/TikTok 链接：
   IG：@
   卖什么：
   评价数 / 粉丝数：
   有没有网站：
   具体观察：（最重要！例如：Vitamin C serum 有 1,200 条评价，很多人说回购第 3 瓶）
   用什么语言：中 / 英 / 马来
```

**「具体观察」是对方会不会回你的关键。** 不要写「你们的产品很好」，要写只有认真看过才知道的事，例如：
- 「你们的 sambal 留言区很多人问东马能不能寄」
- 「看到你们每晚 9 点开直播，新颜色一上就卖完」
- 「IG 每个帖子下面都有人问价钱和尺寸」

也可以直接**截图**店铺页面和 IG 简介贴给 Claude Code。

## 发出之后

| 时间 | 做什么 |
|---|---|
| 第 0 天 | 发开场白 → 告诉 Claude Code「p001 发了」 |
| 第 3 天 | 没回 → Claude Code 给你一条「有用资讯」跟进（用 Shopee 费用计算器算好的数字） |
| 有兴趣 | 做免费样板（`docs/09-netlify-guide.md` 第 D 部分），1–2 天内发出 |
| 第 10 天 | 还没回 → 最后一条，礼貌结束 |
| 对方说不要 | 说谢谢，标记 `do-not-contact`，**永远不再联系** |

## 记数字

每周日跟 Claude Code 说「看这周的数字」：联系了几个、几个回、几个要样板、几个通话、几个成交。第一个月的真实数字比任何猜测都重要。
