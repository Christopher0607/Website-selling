# sales/ — 销售材料

| 文件 | 用途 |
|---|---|
| `playbook.md` | **完整销售手册**：每天流程、找客户、第一次私信、跟进、样板、通话、报价、成交、首月免费转月费、异议、复盘 |
| `agent/` | **销售 AI 助理**（Claude）：网站 AI 客服 + 帮你写开场白、每日清单、回信、报价单、周报。见 `agent/README.md` |
| `scripts.md` | 定稿话术（中 / 英 / 马来文）：找客户标准、第一次私信、跟进、送样板、异议、Instagram 快速回复设定 |
| `prospects.csv` | 潜在客户名单（从 templates 复制）。每天加 20 个；状态流程见 docs/04 §11 |
| `packages.html` | 一页套餐单（中文 + 英文），浏览器打开 → 列印 → 另存为 PDF |
| `proposal-template.md` | 报价单模板（Cartsmith 固定内容已填好） |
| `contract-checklist.md` | 合同要点（拿去请律师做一次模板） |
