# 合同要点（请律师做一次模板，之后每个客户套用）

> 这是要点清单，不是合同。基于 `docs/04-sales-kit.md` §8，加上 Cartsmith 的收费模式（建站费 + 月费 + 免费试用月）。

## A. 建站
- [ ] 双方资料（SSM 名称和号码、地址、联系人）
- [ ] 工作范围：套餐名称、页面、产品数量、付款方式数量、修改轮数（附报价单）
- [ ] 不包含的项目（拍照、logo、广告、多语言……）
- [ ] 客户的责任：提供资料的期限；图片、文字、logo 的版权和合法性；产品本身的合规（化妆品通报、清真声明、功效说法、食品标签）
- [ ] 时间表：从订金 + 完整资料起算；客户延迟就顺延；资料超过 [30] 天没给，项目暂停
- [ ] 付款：50% 订金、50% 余款上线前；逾期处理
- [ ] 所有权：**付清后网站和内容归客户**；我们可以放进作品集（客户可以要求不放）
- [ ] 第三方服务（域名、付款网关、插件、主机）的费用和条款由客户承担，账户用客户名义开

## B. 月费维护 Maintenance
- [ ] 内容（备份、更新、监控、每月修改时间、回复时间）——附套餐表
- [ ] **免费试用期**：上线后第 1 个月（首批客户 2 个月）免费；试用期结束前 7 天通知客户，客户书面确认才开始收费
- [ ] 最短期限：试用期后 6 个月；之后按月续；终止要提前 [30] 天通知
- [ ] 没用完的修改时间不累积；超出的按 [RM__/小时] 报价
- [ ] 不续约 / 终止时：提供完整备份（数据库 + 文件）；协助搬家按「网站搬家」价格收费；我们的服务器保留 30 天后删除
- [ ] 欠费：逾期 [14] 天可以暂停维护；逾期 [30] 天可以暂停托管（先书面通知）

## C. 其他
- [ ] 保密
- [ ] 个人资料：我们代客户处理顾客资料时的责任（PDPA 资料处理者条款）
- [ ] 责任限制：不保证销量或搜索排名；第三方服务中断不负责；赔偿上限为客户已付的金额
- [ ] 终止条款（双方）
- [ ] 适用法律：马来西亚
- [ ] 双方签名和日期
