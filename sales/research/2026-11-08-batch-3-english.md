# 候选商家 · 第 3 批：英文市场、有购买力（2026-11-08，Claude Code 上网找）

> **俊宇的要求：** 主要做英文市场、规模不能太大、商家一定要有足够的购买力。
> **怎么找的：** 只看公开资料：The Edge / Options、Vulcan Post、Grazia、Malay Mail、FMT 的报道和推荐清单。**没有登录，也没有用程式刷 Instagram / Shopee。**
> **这次多了一步：** 第 2 批漏掉了有网站的店（例如壹家其实有 yijiapastry.com）。所以这批每家都**直接试过品牌域名**（.com / .com.my / .my / .co），确认打不开或是空的才放进来。IG 简介里的链接我看不到，还是要你点进去确认。

## A 级标准（五项都要符合）

1. 卖自己的品牌或自己挑选的货（不是转卖大品牌）
2. 有卖得好或做得久的证据（媒体报道、开店多年、有固定客人）
3. 最近还在营业
4. 没有网站（或者网站过期 / 还没建好）
5. **有购买力（这次新加的）：** 至少符合一项：有实体店或咖啡馆；有公司客户（酒店、餐厅、企业）；有寄卖点；产品单价 RM40 以上；花钱做过推广

> 工作台的 AI 打分本来就有「预算信号」这一项（`budget_signal`）。下面每一格都写了「购买力」那一行，AI 会照着打分。

## 开场白要注意（英文市场）

- **用英文写**（工作台「语言」选英文）。语气像朋友，**不要一开口就推销**：先说你看到他们的什么，再问一个问题。
- **冰淇淋店（A6–A8）**：讲「每星期的新口味菜单 + pint 预订 + 指定时段送货」，不用再一个个回 WhatsApp。
- **Artigusto**：可以友善地提醒「你们 IG 上的网站链接显示过期了」，这是实际帮到他们的事。**不要说他们的网站不好。**
- **Best Borneo**：他们的网站正在建，可能已经找了人做。问一句「是不是已经有人在帮你们做网站？」，对方说有就礼貌结束。
- **Ginger Batiks**：圣诞市集季快到了，讲「外籍客人想在市集以外买、寄回国当礼物」。
- **Ilham Ceramics**：讲「给酒店和餐厅看的产品目录 + 询价」，和「游客回家后再订」。
