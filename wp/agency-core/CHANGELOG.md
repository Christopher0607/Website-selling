# Changelog

## 1.9.0 — 2026-11-16（俊宇：工作室网站上的示范全部接上真的 WordPress + WooCommerce，一模一样）
- 新：整个网站的设计（`class-site.php`）：示范网站的页面、样式、程式原样放在 `uploads/agc-skin/`（`site/build.py --wp`），旁边的 `site.json` 是页面自己的清单（菜单、节日套餐、外送区域、营业时间…，`site/tools/export-demo-data.js` 从页面读出来）。每一页都有 `window.AGC_LIVE`：同样的清单，但名称、价钱、简介、库存、照片来自 WooCommerce（后台改了网站马上变；后台新增的产品也会出现）。
- 真的接口（`agc/v1/site/...`）：点餐 / 外送（服务器算价钱、选项、外送区域和运费、时段、优惠码）、节日预购（订金或全额、扣库存）、订位（人数、时段、剩几张桌子、订金）、礼券（付款后自动产生只能用一次的优惠码，12 个月）、询问（外烩、包场、公司礼品）、查订单。
- WordPress 后台新增「Bookings」「Enquiries」（列表、详情、状态）。
- 新：公开示范帐号（`class-demo-access.php`，设定 `demo_public_login`，只在示范模式）：网站上按一下就进 WordPress 后台或店家后台，不用密码；可以看和改订单、产品、库存、优惠码、报表，不能改设定、插件、用户、删除东西、改密码；访客填的名字电话电邮地址 1 小时后自动遮掉。
- 桌上扫码点单：也能用整个网站设计的菜单；示范网站的「See the restaurant's side」直接用示范帐号打开厨房画面。
- 设定新增 `kitchen_busy`（厨房很忙：网上点餐的最早时段往后推）。
- 节日预购网店（Butter & Lantern，2026-11-17）：`site/order` 的 `preorder`：只卖这个节日的产品、在节日窗口内选日子、自取 / 巴生谷送货（邮区）/ 全马快递（东马另算）、每个时段的名额、早鸟折扣（WooCommerce 里是一条负数费用）、网上付款或 DuitNow + 上传收据（`site/receipt`）；顾客选的付款方式、银行、备注、收据档名存在订单里，换一支手机用订单编号 + 电话也查得到同一张单（`site/track` 的 `pre`）。
- 示范模式也不寄「可以取货了」的电邮给访客（`customer_agc_ready`）。
- 修正：每小时遮掉访客资料时，示范自己编的样本订单（例如 DD-2041）不再被遮掉，所以「查样本订单」整天都能用。
