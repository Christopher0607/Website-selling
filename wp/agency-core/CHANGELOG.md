## 1.6.0 — 2026-11-13（店家后台第 2 批：俊宇「更多实际商家会用到的功能，你自己决定」）
- 导出 Excel（.xlsx，浏览器里产生，不用外挂）：报表（订单 + 每天收款 + 热卖三个工作表）、生产（每天要做多少 + 订单）、顾客名单、等通知名单

- 优惠码：新增、修改、停用、删除（打折 % 或减 RM、最低消费、可用次数、有效日期、免运费），看用了几次
- 一键暂停网上接单（概况页开关 + 设定里的公告文字）：网店照样能看、不能下单，每页显示公告
- 送货订单一按 Waze / Google 地图；打印取货清单（每张订单一个方格）；单张订单打印
- 新订单提醒（后台开着时每分钟检查，有新单会提示 + 震动）
- 员工帐号（只有老板能管）：新增员工（店长权限，不能改设定和员工），给对方一次性的设定密码连结（复制或 WhatsApp），移除

- 修正：画面切换太快时，旧画面晚回来的资料不会盖掉新画面；很长的名字不会把手机画面撑宽

## 1.5.0 — 2026-11-13（现代化店家后台）
- 新的店家后台 `/dian/`（也可以用 `/owner/`）：自己的登录页、手机优先（底部分页）+ 电脑侧边栏，可以加到手机主画面像 App 一样用；店长（shop_manager）登录后直接进来，管理员的 WordPress 工具列有「Shop dashboard」
- 概况（今天 / 这一季的数字、截止倒数、接下来的取货日、库存提醒、等通知人数）；订单（待确认付款 / 要做 / 可以取货 / 已完成 / 全部 / 已取消、搜寻、详情、看收据、已收到付款、可以取货、完成、取消、改取货时间、备注、打电话、WhatsApp 预填信息）；生产（每天要做多少、按时段、打印）；产品（价钱、特价、库存、售完、上架 / 隐藏、规格价钱和库存、照片上传（手机先缩小）、新增、删除到回收站）；顾客（名单、等下次开放的号码、复制）；报表（7 / 30 / 90 天、每天已收款图表、热卖、付款和取货方式、导出 CSV）；设定（节日日期和时段、早鸟、店铺资料、公告、DuitNow QR 上传、每个运送区域的运费 / 免运门槛 / 开关）
- REST `agc/v1/owner/*`（登录 + nonce；订单 edit_shop_orders、产品 edit_products、设定 manage_woocommerce）；不用 meta_query

## 1.4.0 — 2026-11-13（RM399 节日预购网店）
- 新增节日预购（Settings → Agency → Festive pre-orders）：截止日 + 倒数（`[agc_festive]`、商店 / 购物车 / 结账上方自动显示），截止后不能下单、可以留 WhatsApp 号码等下次开放；剩几份（按库存，规格加总）；早鸟折扣（购物车自动扣）
- 结账选自取 / 本地送货的日子和时段，每个时段有名额，满了不能选；快递显示寄出说明；运送方式按运送区域判断（区域名字含 `fest_delivery_zone`，默认 Klang Valley）
- 新付款方式：DuitNow QR（手动），订单「保留」，顾客在订单完成页或查订单页上传收据（存在网站公开文件夹外面 `/var/www/<站>/private/receipts`，只有店家能开），店家收到通知电邮；示范模式另外有「示范网上付款」（不收钱）
- 新订单状态「可以取货」（Ready）+ 顾客电邮；订单页 / 查订单页有进度时间线、加入日历；所有订单电邮写上取货 / 送货的日子和时段
- 店家后台「WooCommerce → 节日订单」：这一季订单数、待确认付款、已收款；每天要做多少（已付款 / 待确认分开）；按时段的订单，一键「看收据 / 已收到付款 / 可以取货 / 完成」；打印；想收到通知的号码
- Demo 模式新增「允许测试订单」（`demo_test_orders`）：只开放 DuitNow 示范 QR 和示范网上付款
- 中文翻译 `languages/agency-core-zh_CN`（产生方法见 `languages/make-zh.py`）；宣告支援 WooCommerce 新订单表（HPOS）；不用 meta_query（旧订单表不支援）
