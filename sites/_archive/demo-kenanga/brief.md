# demo-kenanga — Dapur Seri Kenanga（概念作品 Concept Project）

- **风格：** C 温暖自然（warm, homemade）
- **行业：** 食品——自家做的 sambal、kuih、Raya 饼干、礼盒（Shopee / WhatsApp 接单很常见）
- **名字查证：** 2026-11-06 网上搜索 "Dapur Seri Kenanga"，没有找到同名品牌（kenanga = 依兰花；dapur = 厨房）
- **目标顾客：** 25–50 岁的家庭、上班族，买家常口味和节日礼盒；也有公司订礼盒（B2B）
- **说话语气：** 温暖、亲切、像家人；马来文 + 英文
- **颜色：** 陶土红 #8C4A2F、米色 #F6E7D2、点缀姜黄 #E0A030、文字 #2B1D16、背景 #FFFDF8
- **字体：** 标题 Fraunces（温暖衬线）、内文 Nunito（圆润好读）
- **Logo 方向：** 衬线文字 + 小花点缀
- **产品（10 款）：** 见 `products.csv`，价格 RM12–RM128
- **示范重点：** 辣度变体、礼盒、公司订单询价（WhatsApp）、自取选项、东马运费较高
- **注意：** 食品要写清楚保存方式、过敏原、保质期；清真认证只写真的有的（这里是虚构品牌，不写）
